Authentication

Blank fields retain saved keys. Do not change a working device's credentials.

USB pairing

For a new device: connect USB, tap RESET/EN, then pair within 60 seconds. This restarts its app after enrollment. It does not flash firmware or reset Wi-Fi.

For an existing device, import its working keys first to preserve Home Assistant access.

Existing installation

Stop the old companion before importing a copy. Original files and startup entries are preserved.

Diagnostics

Codex CLI must be installed and signed in. Closing this tab keeps Dot running. Logs contain sanitized errors and rotate automatically. Never share private configuration, keys or secret downloads.
